CIFRA — Café de especialidad, medido con precisión

Landing page de marca ficticia creada como pieza de portfolio front-end. Diseño y desarrollo 100% propios · HTML, CSS y JavaScript vanilla, sin frameworks.

⚠️ Sobre este proyecto

CIFRA es una marca ficticia. Este repositorio es un proyecto de demostración técnica y de diseño, pensado para portfolio. No vende café real ni representa a ninguna empresa existente.
Dicho esto, está construido con el mismo nivel de cuidado que le pondría a un producto real: es totalmente funcional, responsive, accesible y fácil de tomar como base para un cliente real o un MVP. 
 El concepto de marca (café trazado por lote, con datos de tueste y extracción) es reutilizable comercialmente tal cual, o adaptable a cualquier otro producto que se venda por "lotes" o 
"ediciones" (vino, chocolate, cerveza artesanal, etc.).

👋 Por qué este proyecto

Lo armé para mostrar cómo pienso un problema de diseño de punta a punta, no solo cómo escribo código:

Investigación de concepto: en vez de una landing genérica, busqué qué hace distinto a un café de especialidad (trazabilidad, curvas de tueste, TDS) y lo convertí en el eje visual y narrativo de toda la página.
Sistema de diseño propio: paleta, tipografía y componentes definidos como decisiones, no como defaults de una plantilla.
Código sin dependencias: todo el front (HTML/CSS/JS) está escrito a mano, sin librerías ni build step, para que cualquiera pueda clonarlo y entenderlo en minutos.
Atención a los detalles que se notan: accesibilidad, responsive real, y micro-interacciones con propósito (no animación por animación).


🎨 Decisiones de diseño

Paleta: fondo casi negro (#0B0D0F) con texto crudo cálido (#F2F0EA) — la tensión entre un fondo frío/técnico y un texto cálido refuerza la idea de "precisión aplicada a algo humano". Acento cian-teal 
(#46E0C4) usado como "color de dato", en vez del verde ácido que suele verse en este tipo de estética.
Elemento de firma: la curva de tueste del hero se repite en miniatura en cada tarjeta de lote, funcionando como hilo conductor visual de toda la página.
Estructura con significado: los códigos de lote (LOTE-014, etc.) reemplazan la numeración genérica de "01 / 02 / 03" — porque en café de especialidad el lote es la unidad real de información.
